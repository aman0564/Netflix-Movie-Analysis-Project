# Netflix-Movie-Analysis-Project
This is the Project for the IBM SkillBuild Data Analytics with AI Internship ,i have created the Netflix Movie Analysis Project with dataset and it will help to predict me movie and provide statistical data .
## Project Description
This project analyzes a movie dataset to extract insights on movie genres, popularity, and ratings. It uses statistical summaries and visualizations to highlight key trends in the data.

## Dataset
The dataset contains various movie attributes such as Title, Genre, Popularity, and Vote_Average.  
**Dataset source:** https://www.kaggle.com/code/joshuaswords/netflix-data-visualization 

## Technologies Used
- Python
- Pandas (for data manipulation)
- Matplotlib (for data visualization)

## Project Structure
- `Netflix Movies.py`: Contains the complete code for data analysis and visualization.
- `requirements.txt`: List of Python libraries needed to run the project.
- `Netflix Movies.docx`: Detailed project report.
- `README.md`: This file.
